# AeroForge AF-RAW001 "Storm"
**Project Designation:** Sector Shield Sentinel  
**Lead Systems Architect:** Benjamin (Ben)  
**Deployment Sector:** Vancouver Island Grid (BC, Canada)

## 🌎 Operational Mission
AeroForge AF-RAW001 "Storm" is an ultra-rugged, 100% off-grid atmospheric monitoring and advanced anomaly warning core. Engineered to withstand the harshest elements of the Pacific Northwest, "Storm" operates completely independently of local Wi-Fi networks or external electrical grids. Reporting comprehensive sensor data every 2 seconds via low-frequency LoRa radio waves to an indoor battery-powered terminal, the system continuously monitors regional airspace telemetry, tracks active wildfire smoke vectors, logs severe coastal storm pressures, and utilizes dual 360-degree external optical camera arrays to track unexplained aerial phenomena.

## 📦 System Inventory Configuration
- **Computing Brain:** Raspberry Pi 5 (8GB LPDDR4X RAM) mounted on custom 66mm PETG standoff plates.
- **Power Core:** ECO-WORTHY 12V 100Ah LiFePO4 Battery featuring integrated Low-Temp Protection & Bluetooth.
- **Signal Interceptor:** RTL-SDR Blog V4 USB Dongle with a dedicated external 1090 MHz tracking mast line.
- **Automated Climate Grid:** 12V Dual Relay Board managing an internal 100W PTC Ceramic Fan Heater (Winter Override) and twin Noctua 40mm brushless exhaust fans (Summer Thermal Release).
- **Multi-Hazard Array:** GPIO-connected MQ-2 Smoke/Gas Sniffer, DHT22 Ambient Temp/Humidity Core, BMP280 Barometric Pressure Sensor, and an external roof-mounted Anemometer (Wind Speed Indicator).
